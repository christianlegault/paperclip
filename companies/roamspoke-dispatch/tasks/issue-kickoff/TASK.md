Check `issue-calendar` in the Dispatch Ledger.

- **Off week:** comment "Off week. Next send <date>" and mark this issue `done`.
- **Send week:**
  1. Confirm the region and featured route from the current `region-shortlist` and
     your recorded pick.
  2. Create the parent `Dispatch #NN: <Region>: <Route> (send YYYY-MM-DD)` and set
     `issue-calendar` to `in-production`.
  3. Create the child `#NN Research: <route>` for the Route Researcher, with
     `parentId` set to the parent.
  4. Comment the parent link here and mark this issue `done`.
