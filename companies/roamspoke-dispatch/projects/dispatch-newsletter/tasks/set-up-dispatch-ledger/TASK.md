Create the long-lived **`Dispatch Ledger`** issue in this project, assign it to
yourself, and set it to `in_progress`. It is never closed. Add the four documents
defined in the `dispatch-workflow` skill:

1. **`issue-calendar`:** biweekly Thursday sends starting **Thursday 2026-10-29**
   (cycle week starting Monday 2026-10-26), then 2026-11-12, 2026-11-26, and
   2026-12-10. Mark every other week as an off week. Flag the December holiday weeks
   as candidates to skip or to turn into "plan ahead" issues, and ask the board.
2. **`region-log`:** an empty table with the columns from the skill.
3. **`performance`:** an empty template covering cost per issue, open rate, click
   rate, CTA clicks, and notes.
4. **`cta-config`:** `status: pending`. The placeholder token is
   `{{COPY_TRIP_URL:dispatch-NN}}`. Proposed UTM convention:
   `utm_source=dispatch&utm_medium=email&utm_campaign=dispatch-NN`.

When the Ledger exists, comment its link here and mark this task `done`.
